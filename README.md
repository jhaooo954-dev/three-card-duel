# 双人游戏厅 v2.0 · 统一房间
一个6位房间码，一次创建/加入，两名玩家共用三种游戏。任何一人选游戏或回大厅，另一人同步切换。切换保留各游戏独立牌局、积分与发牌进度；退出App不主动退出房间，重新打开尝试恢复12小时内未过期房间。显式“退出这个房间”会结束整个房间。
统一入口 https://ten-half-duel-jh.onrender.com/club/ ，APK /club.apk?v=2 ，ZIP /club.zip?v=2 。Android包名com.jh.friendgames，versionCode2，versionName2.0.0。此版本原生签名与上一版本不同，已安装v1的手机需先卸载旧游戏厅再安装v2；旧版各独立游戏不受影响。
三个引擎在同一服务、同一房间身份下运行，游戏视图在同源iframe中展示；每个游戏的建房/输码栏隐藏且不使用。Token只在请求头及本机存储中，服务端只按本人权限发送手牌，不向对方泄露私牌。主房间版本与游戏版本分开；切换代数阻止旧页面迟到操作。重复动作去重，第三人不能进入。
炸金花沿用v1.2规则：无底注、闷看2:1、分1/2/3张看牌、开牌费用不额外翻倍、结算投入保留到下一局、赢家发牌对方先手。大话骰沿用自由喊骰、每人5颗、骰盅动画、任意一方开盅、无积分。十点半沿用整副52张打完换庄、闲家请求庄家发牌、普通/十点半/五张1/2/3倍、庄家特殊牌优先、闲家停牌庄家翻牌，闲家特殊牌双方翻开。
原独立十点半接口和下载保留。房间仅存内存，服务重启或重新部署会清空房间。
运行 node server.cjs；测试 node --test test.cjs club-test.cjs hub-test.cjs。Docker构建安卓APK并验证签名，测试一个房间在三种游戏之间切换、隐私、迟到动作、去重、断线恢复和下载。未做双手机真机测试。

## 系统荷官在线更新
统一房间中的炸金花和十点半新增可见的系统荷官、洗牌和发牌动画。两端根据服务器同一发牌事件播放；重复请求不重新发牌或播放，重连不重播过期动画。动画期间暂缓牌桌按钮操作。荷官事件仅包含编号、时长和收牌座位，不含牌面、牌堆或随机种子。
原来的三个引擎及随机洗牌算法保持原样；房主没有按身份筛选好牌的分支。炸金花仍由房主/上局赢家请求开局，对方先手。十点半仍由庄家请求发牌，整铺才换庄；新铺洗牌，中途补牌及下一小局接着使用原牌堆。骰子保持原样。
已安装统一房间 v2 的 Android App 从原服务载入页面，重开 App 即获取荷官，无需重装或更改签名。服务更新会按原行为清空内存房间，请重新建房。
